# Generic Version — Transport Measurement Suite

PyMeasure-based GUI suite using **only Keithley SMUs and lock-in amplifiers** — no magnet, no cryostat, no temperature logging. Runs on any workstation with the instruments connected.

Based on the ICE version, by **Yoav Sharaby**.

---

## Quick Start

```bash
python "Transport measurements.py"
```

1. Pre-launch dialog appears — tick the instruments in use, verify VISA addresses, **Save & Launch**.
2. Procedure launcher opens — pick a procedure, click **Open window**.
3. Configure parameters, start measurement. Data saved as timestamped CSVs.

## Procedures

| Procedure | Description |
|---|---|
| Resistance time measurement | Monitor lock-in readings over time |
| Resistance gate sweep measurement | Sweep one gate voltage (K2450 or K2604B SMU) |
| Resistance two gate sweep measurement | Sweep two gates simultaneously along a line (density/displacement scans) |
| Resistance two gate mapping measurement | 2D gate × gate map, Snake or Forward/Backward scan modes |

## Supported Instruments

| Instrument | Variable | Connection |
|---|---|---|
| Keithley 2450 (×2) | `Gate_1`, `Gate_2` | VISA (USB/GPIB) |
| Keithley 2604B (dual SMU) | `Dual_gate` (`smua`, `smub`) | VISA (USB/GPIB) |
| Yokogawa GS200 (×2) | `YokoGS200_1`, `YokoGS200_2` | VISA (USB/GPIB) |
| Yokogawa 7651 (×2) | `Yoko7651_1`, `Yoko7651_2` | VISA (USB/GPIB) |
| SRS SR860 (×2) | `SRS860_1`, `SRS860_2` | VISA (USB) |
| SRS SR830 (×3) | `SRS830_1`–`SRS830_3` | VISA (GPIB) |
| Zurich MFLI (×3) | `MFLI_1`–`MFLI_3` | TCP/IP (`zhinst`) |

Drivers live in the parent directory `Instruments/`.

## File Structure

```

├── Transport measurements.py   # GUI launcher entry point
├── config_prelaunch.py         # Pre-launch instrument selection dialog
├── configuration.py            # Instrument initialization (reads instrument_overrides.json)
├── instrument_overrides.json   # Auto-generated by the dialog
├── README.md
└── procedures/
    ├── __init__.py
    ├── base.py                     # GenericProcedure base class, dynamic columns
    ├── resistance_time.py
    ├── resistance_gate_sweep.py
    ├── resistance_two_gate_sweep.py
    └── resistance_two_gate_map.py
```

## Notes

- **Data output:** `~/Desktop/Generic Measurements/` (change `save_dir` in `Transport measurements.py` and `procedures/base.py`).
- **Dynamic columns:** only instruments connected in the pre-launch dialog produce CSV columns; connected-but-unticked instruments in a procedure's **Devices** group give NaN.
- No temperature or magnetic-field columns in this version.
